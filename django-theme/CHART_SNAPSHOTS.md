# 图表快照 v1

## 每日序列

宿主在每次请求中先确认当前站点、账号、模型和统计字段的可见权限，并按租户和对象范围限制查询集，然后按本地日期聚合。主题接收这一份 JSON 数据，同时绘制图表和可读数据表。未获授权时，宿主应省略整张卡片。

```json
{
  "schema_version": 1,
  "metric": "catalog.products_last_updated",
  "as_of": "2026-11-19T04:00:00+00:00",
  "timezone": "Asia/Shanghai",
  "start": "2026-11-17",
  "end": "2026-11-20",
  "state": "ready",
  "points": [
    {"date": "2026-11-17", "value": 0},
    {"date": "2026-11-18", "value": null},
    {"date": "2026-11-19", "value": 3}
  ]
}
```

| 字段 | v1 约定 |
|---|---|
| schema_version、metric | 版本为整数 1。指标标识使用小写字母开头的 ASCII 小写字母、数字、下划线或点，最多 80 字符。宿主负责定义口径与单位。 |
| as_of | 本次取数时间，ISO 8601 时间戳，必须带 UTC 偏移。每次请求重新取数。 |
| timezone、start、end | IANA 时区名和两个 ISO 本地日期。区间左闭右开，覆盖 1 至 90 个自然日。使用该时区各自的午夜边界，夏令时切换日可为 23 或 25 小时。 |
| ready | points 按日期递增，每天恰有一个点。数值为有限 JSON 数字，绝对值最多为 2⁵³−1。0 是观测值，null 表示该日缺测，在图上留空。至少有一个数值。 |
| empty | 宿主确认区间内无可展示的观测，points 为空数组。 |
| error | 本次聚合失败，points 为空数组。页面显示可重试提示，数据中不含原始异常或上一请求的数据。 |

渲染入口为 `nova_admin/daily_chart.html`，上下文传入 `chart_title` 和 `chart_snapshot`。宿主可继承模板的 `chart_controls` 块放置范围筛选器。未知版本、越界、日期顺序错误或畸形快照统一显示错误提示。仅 ready 状态加载本站 ECharts 模块；禁用 JavaScript 或加载失败时，可直接查看同一份快照的数据表。

商品示例按有权查看的商品的 **最近更新时间** 归组，每件商品只计一次。范围选项为近 7 或 30 个自然日（含今天，当天仅统计截至 as_of 的记录），以 Django 当前激活的时区为准；关闭时区支持时使用项目的 TIME_ZONE 解释本地存储时间。区间有商品时，未出现商品的日期计零；整个区间没有匹配商品时显示空态。只有当前站点允许查看商品列表且提供 updated_at 列时才显示该指标。

## 按日期查看商品

在 Demo 首页点击某天的柱形、日期标签或零值日期所在的绘图区，可打开该日的原生商品列表。使用键盘时，在“每日数据与商品明细”上按 Enter 展开，用 Tab 选中日期，再按 Enter。禁用 JavaScript 时表格默认展开。零值日期可打开空列表，缺测值和整卡空态没有明细入口。

宿主可以覆写 `chart_date`，为可下钻的日期输出原生链接 `<a data-nova-chart-day="{{ point.date }}" href="…">`。主题将绘图区的点击交给同一个链接。目标地址由宿主生成，快照 v1 的字段保持兼容。

商品链接携带所选日期和已签名的取数窗口，绑定账号及管理站点。商品列表沿用图表的时区、最近更新时间字段和取数截止时刻，并在每次请求时用当前权限和商品查询集重新筛选。列表中的日期按图表时区显示，搜索、排序和翻页保留日期条件。截止时刻用于排除后来更新的商品；商品被修改、删除或权限变更后，重新打开的列表可能与先前看到的计数不同。

## 按当前状态查看商品

第二张首页卡片用 Chart.js 展示可见商品的当前状态，按草稿、已上架、已归档排列。未选具体日期时统计截至取数时刻的所有日期，7 天或 30 天仅决定每日图的范围。点击条形、状态标签或表格中的状态链接可打开本站商品列表。表格支持键盘和无 JavaScript 操作，数量为零的状态也可打开空列表。

分类快照沿用 v1 的 `schema_version`、`metric`、`as_of`、`timezone`、`state` 和 `points`。分类使用 `"dimension": "category"` 表示按取数时刻统计，日期范围仅用于每日序列。商品状态指标为 `catalog.products_by_status`，一个桶的形式为 `{"key": "draft", "label": "草稿", "value": 3}`。ready 状态含 1 至 64 个按展示顺序排列的桶。key 唯一，以 ASCII 小写字母开头，可含小写字母、数字和下划线，最多 64 字符。label 是最多 120 字符的非空白文本。value 为 0 至 2⁵³−1 的整数或表示缺测的 null，至少一项有观测值。

没有任何可见商品时，宿主返回 empty 和空数组。聚合失败返回 error 和空数组。模板 `nova_admin/category_chart.html` 校验快照后从同一份数据绘图和制表，仅在 ready 时加载本站 Chart.js。宿主可覆写 `category_label`，为有观测值的分类提供带 `data-nova-category` 的原生链接。链接留在页面模板中，快照只携带数据。

## 按日期和状态组合下钻

当本站账号可按日期和状态下钻时，首页两张图共用一个筛选表单。选定状态后，每日图统计该状态的商品。选定日期后，状态图统计该本地自然日的商品。点击图中任意日期或状态会保留另一项条件。“查看符合条件的商品”直接打开已选交集，即使结果为零也可进入。列表中的“返回图表”恢复筛选。更改筛选和切换 7 天或 30 天沿用首次取数的时区和截止时刻，清除筛选可重新取数。

## 联动分析工作台

首页的“联动分析工作台”保留已选日期、状态和签名取数窗口。在工作台点击柱形或用键盘打开数据表中的日期、状态链接，两张图和下方的商品明细会在同一页更新。明细按最近更新优先排序，更新时间使用图表时区。未指定具体日期时，明细覆盖截至取数时刻的所有匹配商品，7 天或 30 天决定每日图的展示范围。

工作台可从任一页导出全部匹配明细。下载按当前账号和站点重新检查对象可见范围与独立导出权限，沿用下方所述的列、行数限制和公式防护。空结果可下载只有表头的 CSV。

在工作台填写“开始日期”和“结束日期”可自选最多 90 个自然日，包含首尾两天，可跨月，也可选择早于近 30 天的历史区间。结束日期最晚为取数时刻所在的本地日期，当天只统计截至该时刻的更新。选择商品状态后，每日图显示该状态在区间内的分布，状态图保留区间内各状态的计数，所选状态的计数与明细总数一致。点击某天可继续下钻，选择“查看整个日期范围”可恢复区间。分页和 CSV 均保留当前日期与状态条件。

商品分类排行按当前日期（或下钻日）和商品状态统计，从顶级分类开始展示。每行汇总该分类及其可见子树中的匹配商品，每件商品在同一级只计一次。点击分类后，两张图、明细和 CSV 都限定到该子树，排行列出各直属子分类的汇总，并单列本级直属商品数。只有分类为空的商品才归入顶层的“未分类”。各行按件数降序排列，同数时按分类 ID 排序，“未分类”排在同数行的最后。

只读账号可逐级下钻。商品范围和分类字段可见性沿用本站商品管理权限。有分类树查看权限时，工作台可展示没有直属商品的祖先分类，并沿用本站分类树的可见节点。仅能查看商品的账号可沿商品分类字段已显示的分类逐级查看。父分类不可见时，其可见子分类独立显示在顶层。仅收录当前条件下有匹配商品的排行行。

点击“本级直属商品”可查看直接归入该分类的商品。两张图、明细、分页和 CSV 都使用这个范围。点击“返回整棵子树”可重新包含各级子分类的商品，保留当前日期、状态和签名取数窗口。

点击分类路径中的祖先可返回该级，点击“清除分类筛选”可返回顶层。两种操作均保留日期、状态、时区和截止时刻。调整日期、状态或翻页会保留所选分类。筛选后没有匹配商品时，明细显示空态，具备独立导出权限的账号可下载只有表头的 CSV。

商品标签排行沿用所选日期、状态和分类范围。多标签商品在每个关联标签下各计一次，只有完全没有标签的商品才计入“未打标签”。按商品数降序排列，同数时按标签 ID 排序，“未打标签”排在同数行的最后。

点击标签后，分类排行、两张图、明细和 CSV 都限定到该标签。标签排行保留其他标签供切换，点击“清除标签筛选”可恢复当前分类内的全部匹配商品。切换标签、分类子树或本级直属商品均沿用原有的时区和截止时刻。下载时重新核对商品、标签字段的可见范围和独立导出权限。

展开“组合筛选标签”，可多选标签并选择“匹配任一标签”或“匹配全部标签”。组合模式下，排行按匹配商品重新计数，选择框仍提供当前日期、状态和分类范围内的其他标签。每件商品在图表、明细和导出中只计一次。“未打标签”表示商品没有任何标签，与具名标签一起选择时，“任一”包含两组商品，“全部”的结果为空。清除标签筛选会保留当前分类和取数窗口。

## 导出下钻列表 CSV

从首页点击日期或商品状态，应用列表筛选后，选择「导出筛选结果为 CSV」。两种导出共用 `catalog.export_product` 权限。只读账号可在获得此权限后下载。下载时按当前站点和账号重新核对商品查看权限、三个导出字段的可见性和每件商品的可见范围。

从联动图表进入的列表和导出都会校验取数窗口的签名，沿用同一时区和截止时刻，并按当前权限重新查询。原生状态筛选也可直接导出，更新时间按当前列表时区显示。文件保留当前搜索、筛选和排序，包含所有匹配页，每次最多 1,000 件。超过上限时页面提示缩小范围。空结果可下载只有表头的 CSV。

固定列依次为 SKU、商品名称、更新时间。时间列表头标明导出使用的时区，记录使用 ISO 8601 格式，开启 Django 时区支持时带 UTC 偏移。文件使用带 BOM 的 UTF-8 编码。所有字段都用标准 CSV 引号转义。SKU 或名称以公式标记、制表符或换行符开头时，会加上可见的 `TEXT: ` 前缀。检测也识别空白、不可见前缀和全角公式标记，数据库中的原值保留。[电子表格公式注入背景](https://community.owasp.org/attacks/CSV_Injection)
