# Changelog

## 0.6.1 · 2026-10-15

正式版本号的发布包，汇总 `0.6.0` 后已合入官方主分支的更新。构建不含任何宿主私有定制；发行包准备不代表已上传 PyPI 或创建公开 Release。兼容范围保持 `Django>=5.2.17,<6.2`、`Python>=3.10`；最低安装声明与实际测试覆盖的区别见 [兼容说明](COMPATIBILITY.md)。

### 实际 Django 后台布局与列表操作

- 桌面端启用 Nova 导航时，采用左侧品牌和导航、右侧工具栏与内容的布局；品牌区与工具栏等高，移除侧栏外围及折叠按钮的多余边线。
- 修复新增按钮、首页增加/修改链接及最近动作的图标间距和垂直对齐。
- 搜索栏增加“隐藏过滤器／显示过滤器”，收起后表格使用释放的宽度；按模型路径保存当前浏览器会话中的折叠状态。
- 宽表增加始终可见的横向滑块和左右按钮。长列表向下滚动时控件吸附在内容区顶部，可直接拖动；支持方向键、Home/End、原表格滚动同步及 RTL，不依赖系统自动隐藏的滚动条。
- 修复首页应用卡片、表单字段组末行和空列表分页区的重复边框；表单及内联组件继续允许日历、关联控件等内容溢出。
- 修复 Django 5.2 动作栏的宽度与内边距叠加造成的手机横向溢出，兼容不同版本的过滤器 DOM 结构。
- 修复通用主题手机和平板搜索行与 Django 原生 `nowrap`/零宽度结果计数的样式冲突：结果计数占独立整行，搜索按钮保持正常高度；作用域限于 Nova，覆盖 Django 的 1024px 响应式断点，保留原生 GET 字段和总数链接。
- 修复 Django 5.2 手机表单的内联表格横向溢出：在没有原生 `.wrapper` 的旧版结构上使用内联自身作为滚动容器，保留输入值及动态添加行；Django 6.x 继续使用原有表格 wrapper。
- 修复 Django 5.2/6.0 平板表单中自动完成和双栏选择器的固有宽度溢出：关联控件在 1024px 及以下可换到下一行，选择器面板在容器内收缩，保留原生选择和关联操作。
- 保留原生模式、登录与弹窗布局，以及原有权限、GET 查询、POST 表单、列表编辑和无 JavaScript 回退；无需模型迁移。
- 更新简体中文译文、回归检查和真实 Django 只读样本。静态样本不运行脚本，折叠与滑块交互需在运行中的 Django 后台使用。

历史功能验证：32 项增强 DOM 测试、23 项布局契约及 23 项导出安全检查通过；Django 5.2/6.1 和独立宿主的桌面、手机浏览器检查覆盖实际拖拽、键盘、表单值保持及边框。这些是 10 月 14 日功能验证，不冒充本次重新执行。见 [布局与列表修复记录](LAYOUT_USABILITY_ZH.md)。

### 已合入的配色更新

- 增加独立配色偏好：医疗青、专业靛、文教紫、零售陶、石墨黑、午夜蓝、松林绿和暖琥珀，可分别搭配浅色、深色或跟随系统外观。
- 加深午夜蓝的蓝色层次，并增加与默认深色明显不同的松林绿和暖琥珀；同步登录、设置及组件预览。配置与升级说明见 [配色说明](PALETTE_PRESETS_ZH.md)。

### 发行与升级

- 版本元数据、运行时版本和翻译头统一为 `0.6.1`；显式声明 MIT 许可证文件和官方源码/文档地址，保持现有开发成熟度分类。
- 同一固定提交生成 sdist、从 sdist 构建的 wheel 和独立静态样本归档；核验许可证、所有运行文件、源码及集成文档、wheel RECORD 和 SHA-256。
- sdist 补齐配色、布局及升级文档；默认安装不包含 Demo、测试依赖或任何宿主代码。
- 升级需重新安装主题，运行宿主原有 `collectstatic` 和静态缓存更新流程；没有新增主题模型迁移，也不需要导入演示数据。保留宿主定制、依赖锁定和可选认证集成；详见 [0.6.1 发行与升级说明](RELEASING.md)。

本次测试结果、证据绑定和未覆盖范围单独记录在 [发行验证记录](RELEASE_VALIDATION.md)，不将历史完整矩阵视为本包全部组合已测。
