# 实际 Django 后台布局与列表操作修复

2026-10-14，在 Domain 的隔离实例中复现并修复。数据库仅含虚构域名和销售页，没有使用业务数据库。

## 问题归属

- 演示的固定左栏与实际后台顶部通栏不同：静态演示和真正的 Django 模板使用不同外壳，差异来自 Nova。复现时 Domain 的主题副本与上游 `9b69e62` 一致。
- 新增按钮的加号挤到文字、最近动作图标偏上：Nova 的通用按钮内边距覆盖了 Django 为背景图标预留的空间；最近动作增加了行内边距，但背景图标仍在旧位置。
- 窄屏长列表难以横向滚动：实际滚轮可以移动表格，但横向滚动条在约 3170px 的列表底部，无法在 900px 高的窗口直接操作。不是宿主禁用了滚动。
- Domain 的“经营概览”是宿主自定义首页模块，保持不变。

## 修复后的行为

- 启用 Nova 导航且宽度大于 1024px 时，品牌和导航占左列，工具栏、面包屑、内容及页脚占右列。保留 Django 原有导航展开/收起、宿主品牌模板及原生模式。
- 新增和查看站点按钮为图标单独留出空间；首页操作和最近动作图标与文字对齐。
- 品牌区与右侧工具栏等高，移除侧栏外围及收起按钮的边线；首页应用卡片只由外框绘制底边，末行背景按圆角裁切。仅含链接的首页卡片采用裁切，表单和内联组件保持溢出可见。
- 搜索栏中的“隐藏过滤器／显示过滤器”控制整栏，收起后列表使用释放的宽度。状态按当前模型路径保存在浏览器会话中；存储不可用时仍能操作。
- 表格溢出时，在上方显示左右按钮和始终可见的横向滑块，向下浏览长列表时吸附在内容区顶部。滑块不依赖系统自动隐藏的滚动条，支持拖拽、滚轮、方向键及 Home/End；窗口或过滤器宽度变化时重新计算，未溢出时自动隐藏。
- 表单字段组末行取消重复底边；空列表分页区使用外层表单的背景与圆角边框，避免内层背景和分隔线覆盖外框。
- 原 GET/POST 表单、查询参数、列表编辑、过滤链接与权限不变；不移动业务控件。无 JavaScript 时原过滤器和导航仍可使用。登录、弹窗、原生及关闭主题不启用新外壳。
