## 人工复核

1. 按 README 启动真实 Django Demo，打开「商品」列表并展开排序说明。
2. 看商品名称/价格的中性提示；先点价格，再点状态，确认优先级数字、升降方向和实际行序。
3. 点击次级列箭头应保留优先级；点击列名会提升为主列；逐个点击 × 直到全部移除。
4. 搜索并筛选后重复操作，确认参数保留；图片和选择框列没有排序提示。
5. 用 Tab / Enter 检查焦点，在明暗主题、紧凑布局和手机视口横向滚动检查表头。
