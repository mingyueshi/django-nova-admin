# 统计图表功能与演示

从侧栏“统计分析”或工作概览中的“统计分析”按钮进入 `/#analytics`。页面包含8类图表、4个关键指标、数据明细和CSV导出，本页使用手写SVG，不依赖远程图表服务或第三方图表库。新增的ECharts、Chart.js与uPlot使用演示位于 `/#charts`，见 [开源图表指南](CHART_LIBRARIES.md)。

## 图表与交互

| 图表 | 场景 | 可操作功能 |
| --- | --- | --- |
| 折线 / 面积图 | 支付金额、订单、新增用户趋势 | 三种指标、按日/每7天汇总、本期/上期对比、隐藏图例、数据点读数 |
| 堆叠 / 分组柱状图 | 新客与复购订单构成 | 两种布局、独立显示/隐藏两类订单 |
| 环形 / 饼图 | 渠道金额贡献 | 切换样式，选择扇区或渠道名称联动筛选整页 |
| 横向排行 | 商品类别支付金额 | 金额降序、订单数、金额占比和相对最长条形 |
| 转化漏斗 | 访问、浏览、结账、支付 | 同一批会话，显示上一步转化率及各阶段数值 |
| 星期 × 小时热力图 | 订单活跃时段 | 168个单元格、精确订单数、键盘方向键与触摸查看 |
| 散点图 | 订单与客单价关系 | 每点代表一天，横轴订单、纵轴客单价、大小为访问会话数 |
| 圆环进度 | 支付金额目标 | 自定义目标、完成率、距目标/超出目标金额 |

时间筛选支持7/30/90天，来源支持全部、自然访问、搜索推广、社交媒体、合作渠道。筛选会更新全部图表、指标、表格与导出；趋势粒度和图例只改变对应图表的呈现，不改变导出的原始每日数据。图表操作在本页会话中保留，刷新恢复默认；不写入已有业务记录或浏览器偏好。

数据点可以悬停、点击或用Tab聚焦，再用方向键、Home/End切换。扇区支持Enter/空格下钻渠道。小屏的趋势、柱状、热力图等在各自区域横向滚动；页面本身保持在视口内。大额指标显示万元缩写，原始精确金额保留在标题提示、可访问名称、明细与CSV中。

## 数据口径与边界

数据来自 `dist/js/analytics-data.js` 中的固定合成会话样本，快照截至2026-10-23，按北京时间演示日与时段。数据与用户/商品编辑器中的记录相互独立，没有真实订单、账户、支付、统计接口或服务端权限实现。

- 支付金额以整数分聚合，页面与导出转成元；商品、渠道、每日及周汇总金额与关键指标总计一致。
- 支付订单 = 新客订单 + 复购订单；平均客单价 = 支付金额 ÷ 支付订单。
- 支付转化率 = 支付订单 ÷ 访问会话数。每个模拟会话最多产生一笔支付，漏斗各阶段来自同一批会话。指标旁的增幅为相对上期的变化率，不是百分点变化。
- 上期是紧邻本期、天数相同的区间。周汇总从筛选起点每7天分组，最后一段可能不足7天。
- 热力图把每日订单按固定小时权重分配，采用整数余数分配保留每一单；它不是独立采集的实时监控数据。
- 自动参考目标按天数和渠道数变化；自定义目标在筛选变化时保留。目标超额时圆环最多绘制100%，中心仍显示真实比例。
- “无数据”显示未知值和空态；“全零数据”保留日期与零值。分母为零时不计算占比、客单价或增幅，不绘制虚构的饼图分区。

## 源码与接入

- `dist/js/analytics-data.js`：`analyticsSnapshot()` 提供同一份聚合结果，`analyticsBuckets()` 提供按日/周分组，`analyticsCsv()` 导出当前每日结果。
- `dist/js/analytics.js`：`initAnalytics()` / `renderAnalytics()` 接入现有路由、通知与页面标题，使用本地SVG绘图。
- `dist/analytics.css`：独立、带作用域的图表样式，沿用现有主题变量和明暗配色；已单独列入CSS预算。

CSV使用UTF-8 BOM、标准引号转义和CRLF，含快照范围、渠道、数据示例及逐日精确值。文件名标注天数与渠道。下载不可用时给出失败提示，仍可查看明细表。

接入真实Django项目时，需要替换数据模块的样本来源并接入项目自己的统计接口，再由服务端按登录用户、模型权限、时区和数据归属聚合。此轮交付的是静态演示功能，没有把模拟统计接入通用Django主题运行包，也没有新增后台API。
