## 0. 结论摘要（TL;DR）

初始诊断集中于以下三处；各阶段原始事实保留，最新整改及线上验收状态见后文：

1. **共享呈现资产缺少完整契约**：两套实现有意承担不同功能；图标已有共同生成源与一致性校验，不能笼统说所有同步依赖人工。但登录 CSS 确有未同步差异，应先收口明确共享的部分。
2. **Demo 模板选择过度绑定版本号**：初始代码按 `django.VERSION[:2]` 白名单选择已审查片段。10 月 19 日线上 main 实验回归运行 335 项，出现 55 个错误、2 项跳过，其中 54 个版本闸门异常、1 个版本映射 KeyError；R2随后改为模板内容签名匹配。
3. **历史说明失效及验证缺口**：远端、快速 CI 和漂移 cron 均已存在；macOS ARM64也有发行验证记录。2026-10-24已补齐T2、T3-4/5/6本地独立验收和用户回报的真实iPhone Safari/VoiceOver最小范围；随后特性分支`ef58c7d`的线上完整矩阵及手动上游预警也已独立接受。默认分支尚未合入，人工音频听辨继续跳过未验收，其他设备/浏览器/读屏及生产边界不扩大，不能据此宣称全站WCAG符合性。

初始诊断建议的优先顺序：R2 模板选择缺陷 → R3 现有告警核验及说明更新 → R1 明确共享资产的契约 → T 类覆盖补齐。后续完成情况以各项最新记录为准；F类仍是可选需求，不能因出现在报告中就视为已确认产品范围。

## 1. 项目概况

| 组成 | 用途 | 数据与交互 |
|---|---|---|
| `dist/` | 纯 HTML/CSS/JS 交互预览源码 | 浏览器本地 mock，无真实权限/业务 API |
| `django-theme/src/nova_admin/` | 可安装的 Django Admin 主题 | 复用原生 AdminSite/ModelAdmin/认证/权限/CSRF |
| `django-theme/demo/` | 可运行 Demo + 图片列示例 | 本地 SQLite，真实增删改查 |
| `tests/` | 当前前端1298项Node/jsdom检查 | 不代表浏览器视觉/真机认证 |
| `django-theme/tests/` | 核心/验证码/Axes 独立测试 | 精确补丁版本矩阵 |

**已有能力（主题侧）**：明暗/auto/原生模式、16 套配色预设、设计令牌与品牌配置、导航收藏/常用模型/图标/徽标 hook、320 个开源图标、密度预设、登录页重设计、可选验证码（django-simple-captcha）、可选 Axes 8.3.1 锁定桥接、中文企业预设、分页/图片列示例、Django 系统自检（W001–W003）、上游模板漂移预警工具、Compose 部署示例。

**测试口径**：7 组/28 环境、核心313通过+2跳过、CAPTCHA22项和Axes15项来自历史轮次，不能拼成当前HEAD验收。初始本地复核在macOS ARM64/Node24.21.0先跑1270项前端，R1后1274项；图标320项、配色角色2908项也属于各自阶段证据。最新`ef58c7d`线上full为28环境、3 Node、3版Axes，核心各424运行/421通过/3可选跳过、验证码各57通过、Axes各16通过、每Node1298前端+230主题JS；详细运行与独立回执见R3和台账，不扩大浏览器/真机/生产验收。

### 2.3 功能可扩展项（候选需求，不作为已确认缺陷或本轮自动实施范围）

以下 P1/P2/P3 为原报告的建议顺序，不是已证明故障严重度。历史 `REVIEW_RESPONSE.md` 明确它们需业务/身份/权限设计；没有证据支持“方向已定、用户呼声最大”。先完成风险收口，再另行确定具体功能与验收范围。

#### F1（P1）可插拔仪表盘（Dashboard）

- **现状**：首页只有应用/模型卡片；`AdminSite.index_template` 是公开扩展点，但 Nova 无示例。
- **建议**：若确定实施，先定义宿主的可见对象与可统计字段范围，检查模型/对象权限后再聚合；仅调用 `get_queryset` 并不自动提供业务对象级过滤。不得将预览的模拟 KPI 当成真实统计。

#### F2（P1）行操作（Row actions）范式

- **现状**：已有原生 change 链接、缩略图授权跳转与 `list_editable`；尚无独立的逐行 change/delete 操作列范式，不能笼统称没有行内交互。
- **建议**：提供 `@admin.display` + `format_html` 生成 change/delete 链接的受控示例（保留原生确认 + CSRF POST）。

#### F3（P1）导入 / 导出的受控示例

- **现状**：`INTEGRATION_GUIDE.md` 只有文字指南。
- **建议**：导出（CSV 公式注入防护、列白名单）+ 导入（上传→解析校验→预览差异→确认提交四步）落成可复制的 Demo 实现。

#### F4（P1）富文本 / 私有图片上传真实示例

- **现状**：`media.py` 是合成图集 key，明确声明不是私有媒体方案。
- **建议**：补 `ImageField` + 授权下载/预览 + 内容净化（不可信 SVG/HTML 隔离）的参考实现。

#### F5（P2）账户安全补全

- **现状**：登录页已在存在 `admin_password_reset` URL 时显示入口，但 Demo 未接；Axes（锁定）已接，MFA、"记住我"、会话时长未做。
- **建议**：密码重置流程对接示例（含防枚举响应）；MFA 作为安全 extra 的下一环。

#### F6（P3）视觉 / 体验增强

- 即时外观切换、打印样式（`@media print`）、favicon 打包示例、`date_hierarchy`/缺货警示/新闻日期校验示例、空状态插画。

### 2.4 技术债 / 边界（已声明，需留意）

| 编号 | 事项 | 严重度 | 说明 |
|---|---|---|---|
